# Study Pack JSON

Use an array or {"items": []}. Each item may contain topic, term, definition, question, choices (4), correct (0=A, 1=B, 2=C, 3=D), explanation, and source.

For this Illinois Broker project, correct answers must be grounded in the user's supplied course sources. New question stems/scenarios/distractors are allowed when they test source-supported facts.
